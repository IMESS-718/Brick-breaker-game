#  Brick Breaker Game

A classic Brick Breaker arcade game developed using Python and Pygame.

##  About the Project

This project recreates the classic Brick Breaker game, where the player controls a paddle to bounce a ball and break bricks. The objective is to destroy the bricks while keeping the ball in play.

##  Features

- Paddle movement to control the ball
- Ball physics and brick collision detection
- Score tracking
- High-score storage
- Interactive arcade-style gameplay

##  Technologies Used

- Python
- Pygame

##  How to Run

1. Install Python on your computer.
2. Install Pygame:

   ```bash
   pip install pygame
   ```

3. Download or clone this repository.
4. Open a terminal in the project folder.
5. Run the game:

   ```bash
   python brick_breaker.py
   ```
